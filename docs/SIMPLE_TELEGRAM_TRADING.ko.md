# 심플 텔레그램 자동 가상매매

이 모드는 ChatGPT 예약 작업의 결과를 사용자가 개인 텔레그램 봇에게 전달하면
맥 프로그램이 가격 규칙을 등록하고 KIS 시세로 자동 가상매매하는 방식입니다.
OpenAI API, Custom GPT Action, ngrok 및 OTP를 사용하지 않습니다.

실제 KIS 주문은 전송하지 않습니다. 모든 주문 결정은 기존과 같이 가상 체결되고
KIS 주문 의도만 `record_only`로 로컬 SQLite에 기록됩니다.

## 자금 및 실행 제한

- 한국 시장 가상자금: 3,000,000원
- 한 메시지의 종목: 최대 3개
- 동시 보유 또는 진입대기: 최대 2종목
- 소수점 수량: 사용하지 않음
- 수량: 손절 위험, 남은 현금 및 최대수량 중 최솟값으로 자동 계산
- 진입 가능시간: 09:10~14:30 KST
- 장 마감 강제청산: 공식 정규장 종료 15분 전
- 같은 메시지: 한 번만 처리
- 실행 중이거나 청산 완료된 당일 계획: 새 메시지로 교체하지 않음

## ChatGPT 예약 작업 출력 양식

예약 작업에는 설명 없이 아래 다섯 줄만 출력하도록 지시합니다.

```text
종목명: 삼성전자
종목코드: 005930
진입가격: 70000
익절가격: 72800
손절가격: 68600
```

여러 종목은 `---`로 구분합니다. 후보가 없으면 `오늘 패스`만 출력합니다.
종목코드는 앞자리 0을 보존한 6자리 문자열이어야 합니다. 가격에는 쉼표와 `원`을
사용해도 되지만 다른 문장이나 필드를 추가하면 전체 메시지가 거절됩니다.

예약 작업 지침 예시는 다음과 같습니다.

```text
매 실행 시점의 최신 웹 뉴스·공시·시장 흐름을 확인하고 한국 주식 후보를 최대
3개 판단한다. 결과에는 설명, 출처, 제목, 인사말 및 마크다운을 넣지 말고 종목마다
아래 다섯 줄만 출력한다. 여러 종목은 --- 한 줄로 구분한다. 적합한 종목이 없으면
오늘 패스만 출력한다.

종목명: 실제 종목명
종목코드: 6자리 코드
진입가격: 정수
익절가격: 정수
손절가격: 정수
```

현재는 `config/universe.yaml`의 한국 종목만 허용합니다. 종목명과 종목코드가
등록 정보와 정확히 일치해야 합니다.

## 가격 의미

- 진입가격: 최대 매수 지정가입니다. KIS ask가 이 가격보다 높으면 대기합니다.
- 익절가격: 보유수량 전량을 매도하는 목표가격입니다.
- 손절가격: KIS bid가 이 가격 이하가 되면 가상 손절을 시작합니다.

비용을 반영한 최초 손익비가 1.5 미만이거나 손절폭이 진입가격의 0.25%~3% 범위를
벗어나면 메시지를 거절합니다. 프로그램은 가격에 도달하기 전까지 최신 KIS 시세,
정상 거래 상태, 정상 호가, 데이터 지연 및 총위험 한도를 계속 확인합니다.

## 환경변수

```dotenv
TELEGRAM_BOT_TOKEN=BotFather에서_받은_전체_토큰
TELEGRAM_CHAT_ID=개인채팅_ID
TELEGRAM_TRADE_POLL_ENABLED=true
TELEGRAM_TRADE_DATABASE_PATH=data/simple_telegram.db
TELEGRAM_TRADE_POLL_TIMEOUT_SECONDS=25
TELEGRAM_TRADE_MESSAGE_MAX_AGE_SECONDS=120
KIS_ORDER_MODE=record_only
```

단순 모드는 기존 복잡한 계획 원장과 분리된 `data/simple_telegram.db`를 사용합니다.
따라서 이전 가상 포트폴리오 잔액이나 실행 중 계획이 300만 원 신규 계좌에 섞이지
않습니다.

봇과 반드시 개인 채팅을 사용해야 합니다. 프로그램은 메시지의 `chat.id`,
`from.id` 및 설정된 `TELEGRAM_CHAT_ID`가 모두 같은 경우에만 처리합니다.

BotFather 또는 다른 서비스에 webhook을 등록한 봇은 `getUpdates` 장기 폴링과
동시에 사용할 수 없습니다. 기존 webhook이 있다면 제거한 뒤 실행합니다.

## 처리 결과

성공하면 다음 한 줄만 회신합니다.

```text
등록완료: 005930 / 자동 가상매매
```

잘못된 형식이나 가격은 `등록 거절: 사유`로 회신합니다. `오늘 패스`는 주문을
생성하지 않고 `오늘 패스: 주문 없음`으로 회신합니다.

Telegram 단순 모드를 켜면 `/v1/gpt-actions/*` 경로는 HTTP 410으로 차단되고
정기 OTP도 발급하지 않습니다. Telegram 메시지를 전달한 행위 자체를 당일
가상매매 승인으로 취급합니다.
